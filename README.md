# Inventory-Management-System
A Python-based inventory management system that allows users to track products, quantities, and inventory information using file processing.

Overview

This project provides a simple command-line inventory management system. Users can view inventory, update quantities, add products, and maintain inventory data using a text file.

Features:

View inventory
Add inventory items
Update inventory quantities
Track product information
Read inventory data from a file
Write updated inventory data back to a file
Input validation
Exit using a sentinel value

Technologies:

Python
Lists
Functions
Loops
Conditional statements
File I/O
String processing
File Processing

Inventory information is stored in:

inventory.txt

The program reads the existing inventory when it starts and can write updated information back to the file.

Concepts Demonstrated:

Python functions
Lists
Loops
Conditional logic
File reading and writing
String manipulation
User input
Sentinel-controlled loops

How to Run:

Clone the repository.
Make sure Python is installed.
Open the project in VS Code, PyCharm, or another Python IDE.
Run the Python program.
Follow the prompts to manage inventory.

Purpose:

This project was created to practice Python programming and file-processing concepts while developing a practical inventory management application.
